# Contributing to Awesome Cybersecurity Datasets

First off, thank you for considering contributing to `Awesome-Cybersecurity-Datasets`! It's people like you that make this list such a great resource for the community.

As the new maintainers (SystemHelpdesk), we actively review all submissions on a weekly basis. To ensure your dataset gets approved quickly, please follow these guidelines.

## How to Submit a Dataset

1. **Check for duplicates**: Before submitting, please check the existing list to make sure your dataset isn't already featured.
2. **Fork and Clone**: Fork this repository and clone it to your local machine.
3. **Add your entry**: 
   - Add your dataset to the most appropriate category in `README.md`.
   - If no category fits, you may propose a new one.
   - Use the following format:
     `* [Dataset Name](http://link-to-dataset.com) - A brief, objective description of what the dataset contains, how it was collected, and what it is best used for.`
4. **Ensure Quality**: The link must be alive and point directly to the dataset or its official documentation page. Do not link to blog spam or paywalled data.
5. **Open a Pull Request**: Submit your PR. We will review it shortly!

## Quality Standards
We manually curate this list to maintain high E-E-A-T (Experience, Expertise, Authoritativeness, and Trustworthiness) standards. 
- Datasets must be genuinely useful for cybersecurity research, machine learning, or incident response.
- Datasets must have clear licensing (open-source preferred).
- We reserve the right to reject low-quality or irrelevant submissions.

Happy learning, and thank you for contributing!
